Setup sheet

How to let Claude ship from your design system without inventing values

Follow or invent are the only two options most agents have. The pipeline adds a third — propose it at the source — and makes the other two machine-detectable, so a hardcoded value fails the build instead of reaching main.

1Where it lives
{client}-token-pipeline/
├── tokens/*.json        ← synced from Figma
├── pipeline.config.mjs  ← names, not ids
├── sd.config.mjs        ← Style Dictionary v4
├── scripts/
│   ├── scaffold-client.mjs
│   ├── generate-docs.mjs   ← router
│   └── generate-report.mjs ← the gate
├── templates/agent-rules.md
├── dist/{light,dark}/   ← generated
└── CLAUDE.md / AGENTS.md ← generated

{client}-app/            consumes
└── vendor/tokens.css    ← synced, committed
2Lock levels · direction of truth
  • ▲Figma: the origin. Every token change starts here.
  • ▲tokens/*.json: synced. Never hand-authored.
  • ▲dist/: generated. Never hand-edited.
  • ▲Primitives: locked. The surface never reads them.
  • △Semantic layer: the only thing components consume.
  • △Composition: open. Build freely from semantics.
3The one loop · no other path
01Author in Figma. A variable, with its usage rule in the description.
02Sync. Collections matched by name → tokens/*.json.
03Build. Style Dictionary → dist/{light,dark} + report.
04Consume the token. Semantic layer only, in the app.
4The proposal rule
needs a value→ propose in Figma→ rebuild · use the token

A value the surface needs but the tokens don't have is a token proposal, never a literal. It is authored at the source and flows down — because a value invented in code is a value Figma will never know about.

Not "ask permission." The third option is a real, cheap path: one JSON-shaped edit at the origin, one rebuild. Making it cheaper than hacking is the whole trick.

5The gate · generated report
Build integrity, per modeGATE

Ten checks (build integrity runs once per mode), regenerated from the real build every time, so the report cannot describe a system that no longer exists. Nine of them fail the build, rather than shipping as a warning nobody reads.

The colour audit is the deliberate exception. A hex matching a token's value doesn't make that token the semantically right one, so it names the colours with nothing behind them and leaves the judgement to a person.

6What the client owns

Their tokens, their outputs, their pipeline, running in their own repositories. The build machinery, the scaffold and the templates stay Orin's.

The router is generated, not written — it carries their real Figma file and token prefix because it's rendered from one template plus their config. A hand-written router is a doc that rots; this one is an output.

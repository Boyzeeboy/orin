The layer above the tokens

A token gate decides whether a value is allowed. Almost nothing decides whether a pattern is. Three parts close that gap, and the order they arrive in is the whole difference between a system and a pile of one-offs.

The gap

A value layer forbids invention everywhere, so it needs no zoning.

A pattern layer is different: composition is exactly where an agent is allowed to be generative.

The problem — an agent has two options

Faced with something the system cannot express, most agents can only follow the rules or break them. Breaking them is silent, it looks like progress, and it is how a library grows forty near-identical components nobody chose. The fix is a third option.

1Available today

Follow

The system has a pattern for this. The agent instantiates it and everything downstream stays true.

Works
2Available today

Break

The system has nothing, so the agent invents one. Nothing fails, nothing is recorded, and nobody finds out until the next rebrand.

Silent
3The missing one

Propose

The system has nothing, so the agent says so, in a structured record, and builds from locked primitives in the meantime.

The third option
The three parts
1What exists

The contract

Every pattern, what it is built from, which tokens it may use, and which zones are closed. Structured data a script can diff against the design source and the code.

Generated, never written
2When it has no answer

The proposal

A record carrying the gap, what it would be built from, and which existing patterns were ruled out and why. Captured at the moment of proposing rather than remembered later.

Lands at the source
3Before it is real

The graduation

A proposal becomes a pattern after two genuine uses. A counter is not taste, it is auditable, and a report can read it.

Two uses, then it exists
Part 3 is the one that gets dropped, and it is the one that matters.

Without a graduation rule you collect forty one-off inventions and no system. The counter also surfaces the opposite failure: a proposal sitting at one use for three months is a pattern nobody actually needed.

GapWhat the system cannot express. Stated as a need, never as a solution.
Built fromWhich locked primitives it composes. If it cannot be built from them, that is a finding about the primitives.

Where each part lives

Prose gets understood, not checked. Write a rule into a markdown file and a model will mostly follow it, with nothing at the end telling you where it drifted. So the split is by what the rule has to survive: judgement in prose, exactness in data, enforcement outside both.

01 The contract Structured data, generated from the source it describes, so it cannot drift from the system it claims to document. Data
02 The guidance Prose in the router an agent reads first. Judgement calls where roughly right is fine and a person reviews the output anyway. Generated, not hand-maintained. Prose
03 The check Continuous integration, in the repository, failing a build. Never in the prose, because a rule an agent can ignore is the "follow or break" problem again. Gate
04 The proposal At the source of truth, wherever that is. In a design-first pipeline a graduated pattern becomes a real component there and flows down like everything else. The written record is reasoning, never the thing the build consumes. Source
The skill is the packaging, not the mechanism
A skill carries
  • The guidance, in prose, at the moment of generation.
  • The contract, bundled as data the agent reads rather than infers.
  • The propose-and-graduate rules, so the third option is available at all.
A skill cannot carry
  • Enforcement. An agent can skip a skill, misread it, or run without it, and nothing anywhere fails.
  • A version. Unless it ships from a repository with releases like everything else.
  • A verdict. A model scoring its own work is softer than a build that goes red.

Order matters more than any single part

A rule that says "use the raised surface colour" is worth nothing if that value does not resolve, is not versioned, or means something different in the code. The pattern layer inherits whatever the value layer is worth.

Which is why this comes second. Build it on a substrate that holds still and it constrains generation towards something true. Build it on one that does not and it produces output that is confident, consistent and wrong, at speed.
